Arbetsprocess

Webbplatsen byggdes med hjälp av Vite som grund för NodeJS, som gjorde det enklare att organisera projektet och automatisera vissa moment. Jag startade ett Git-repo och skapade två huvudbrancher: development för den löpande utvecklingen och testningen, och main för den färdiga versionen som ska publiceras. För att slippa versionhantera stora mappar som node_modules la jag till dem i .gitignore.

Projektet strukturerades med mappar för CSS, JavaScript och bilder under src, och webbplatsen består av tre sidor: startsida, en bildsida som innehåller fem bilder, och denna sida som beskriver arbetsprocessen. Jag byggde en navigeringsmeny för enkel åtkomst mellan sidorna, och sidans namn visas i sidhuvudet. Designen är responsiv och anpassar sig till olika skärmstorlekar med hjälp av media queries.

Automatisering har varit en viktig del av arbetet. CSS och JavaScript minifierades automatiskt vid byggprocessen med hjälp av Vite, och bilder optimerades och konverterades till moderna format som WebP med kvalitet 75 när dom uppdaterades genom pluginet vite-plugin-image-optimizer. För att se resultatet använde jag npm run build för att skapa en publiceringsmapp med optimerade filer och npm run preview för att kontrollera hur sidan ser ut innan publicering.

Alla installerade paket finns listade i package.json, vilket gör att projektet enkelt kan återställas med npm install på en ny dator. Under hela utvecklingen har jag använt Git och GitHub för att spåra ändringar, med regelbundna commits för att dokumentera arbetet. Bilderna optimeras automatiskt varje gång de uppdateras, vilket säkerställer att den publicerade sidan alltid är optimerad.

Webbplatsen publiceras automatiskt via GitHub när ändringar görs i main-branchen, och dist-mappen används som källa för publicerade filer. Arbetsprocessen har gjort det lättare att jobba strukturerat, hålla koll på ändringar och säkerställa att sidan alltid är optimerad och redo att publiceras. Jag tycker att det har varit lärorikt att kombinera verktyg för att automatisera projektet, även om det också varit endel att ta in.
